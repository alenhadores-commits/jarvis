IA ROUTER LOCAL — GUIA RÁPIDA
================================

PASTA DO PROJETO
C:\Users\almei\IA_ROUTER

O QUE É
-------
Um roteador local de APIs de IA. Ele funciona como uma API compatível com o padrão OpenAI e escolhe automaticamente entre os provedores configurados.

SERVIDOR
--------
Host: 127.0.0.1
Porta: 8765
API base: http://127.0.0.1:8765/v1

COMO INICIAR
------------
Abra o PowerShell e execute:

cd C:\Users\almei\IA_ROUTER
python -m uvicorn api_router:app --host 127.0.0.1 --port 8765

Para verificar se está online:

Invoke-RestMethod http://127.0.0.1:8765/status | ConvertTo-Json -Depth 10

USO NORMAL
----------

Endpoint principal:

POST http://127.0.0.1:8765/v1/chat/completions

Exemplo PowerShell:

$body = @{
    messages = @(
        @{
            role = "user"
            content = "Responda apenas OK."
        }
    )
    temperature = 0
    max_tokens = 16
} | ConvertTo-Json -Depth 8

Invoke-RestMethod `
    -Uri "http://127.0.0.1:8765/v1/chat/completions" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body | ConvertTo-Json -Depth 10

A resposta informa:
- modelo
- resposta
- tokens
- provedor utilizado


ENDPOINTS IMPORTANTES
---------------------

/status
    Estado geral do Router.

/providers
    Provedores configurados e estado.

/usage
    Uso acumulado, chamadas, erros e tokens.

/quota
    Informações de quota que o Router conseguiu descobrir.

/v1/models
    Modelos expostos pelo Router.

/outbound
    Informações sobre saídas/requisições externas.

/ws
    WebSocket do Router.
    A base já existe, mas o streaming completo ainda não foi finalizado.


CONTABILIZAÇÃO DE TOKENS
------------------------

O Router registra:

- prompt_tokens
- output/completion_tokens
- total_tokens
- chamadas
- erros
- rate limits
- latência
- remaining requests
- remaining tokens
- informações de quota quando disponíveis

IMPORTANTE:

reasoning_tokens é um detalhamento de completion_tokens.

Ele NÃO deve ser somado novamente ao output.

Isso evita dupla contagem.


QUOTA
-----

O endpoint /quota consulta o que estiver disponível nas APIs/provedores.

Se um provedor não informar o limite real, o Router mantém o valor como desconhecido.

NUNCA inventar limites de quota.


ALERTA DE QUOTA
---------------

ROUTER_QUOTA_ALERT_PERCENT = 10%

O Router alerta quando uma quota conhecida chega a 10% ou menos.

O alerta é limpo quando volta acima de 15%.

RESUMO EM UMA FRASE
-------------------

IA_ROUTER é a camada local que recebe uma chamada de IA, escolhe um provedor disponível, executa a requisição, registra uso/tokens/quota e pode fazer fallback para outro provedor.
